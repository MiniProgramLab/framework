MiniLoom · 织微小程序开发框架

首期微信 Skyline；平台、渲染与功能按契约注册。箭头表示调用或向宿主提供实现。

一套产品，明确分工

  • • Core、组件、CLI 与编辑器围绕同一套契约协作。
  • • 组件共享属性、状态行为与主题，原生视图按目标选择。

注册扩展，按需装配

  • • 微信 adapter 与 Skyline renderer 分离。
  • • 新增抖音、支付宝时提供 adapter、UI 视图及语言描述。
  • • 共享协议不等于共享可变全局容器。

保留当前工程保证

  • • 首期继续支持 TypeScript、WXML、SCSS/Less。
  • • 私有配置始终保留原位置，构建不会覆盖其字节内容。
  • • 本图为设计提案；未来平台不代表已经实现。
